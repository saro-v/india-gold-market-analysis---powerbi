# GitHub Upload Guide

## 1. Create the repository

Use this repository name:

`india-gold-market-analysis-powerbi`

Suggested description:

`Power BI analysis of gold prices, consumption, demand and regional trends in India, with supporting silver price trends.`

Set the repository to **Public** if that is required for your college submission.

Do not create a second README if you are uploading this prepared folder. Keep the README from this package.

## 2. Upload the project folder

The repository root should look like this:

```text
README.md
index.html
assets/
data/
docs/
powerbi/
```

The two dashboard images in `assets/` have been updated to the current two-page report.

## 3. Add the final PBIX

The current file is already included as:

```text
powerbi/India Gold Market Analysis.pbix
```

If GitHub rejects the file because of size, use Git LFS or keep the PBIX as a separate submission file according to your college rules.

## 4. Check the important files

Before moving on, open these files on GitHub:

- `README.md`
- `assets/dashboard-page-1.png`
- `assets/dashboard-page-2.png`
- `docs/project-overview.md`
- `docs/data-dictionary.md`
- `docs/methodology.md`
- `docs/sources-and-limitations.md`
- `powerbi/India Gold Market Analysis.pbix`

## 5. Enable GitHub Pages

If your staff asked for a GitHub **site**, not only a repository:

1. Open the repository.
2. Go to **Settings**.
3. Open **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch.
6. Select `/ (root)`.
7. Click **Save**.
8. Wait for the deployment.
9. Open **Visit site**.

The `index.html` file is already prepared for this.

GitHub Pages can display the project website and dashboard images. It does not run the `.pbix` file inside the browser.

## 6. Final check

Before submitting the GitHub link:

- [ ] Repository name is correct.
- [ ] Repository is public if required.
- [ ] README opens correctly.
- [ ] Both current dashboard images are visible.
- [ ] Four CSV files are present.
- [ ] Excel workbook is present.
- [ ] PBIX is present if required.
- [ ] Documentation opens correctly.
- [ ] State-level estimates are clearly labelled.
- [ ] No temporary files or personal information are included.
- [ ] GitHub Pages opens correctly if a website was requested.
