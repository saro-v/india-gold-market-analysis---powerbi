# Sources and Limitations

## Source basis

| Source | Used for |
|---|---|
| Indian Bullion and Jewellers Association (IBJA) | Daily bullion rates |
| Economic Times | Selected 22K jeweller retail-rate observations |
| World Gold Council | India quarterly gold-demand figures |
| World Gold Council | Regional jewellery-demand shares used for the state estimate |
| Project calculation | State-wise analytical allocation |

## Important limitation

A current official state-by-state gold-consumption dataset in the required format was not available.

For that reason, `State_Gold_Consumption` is a **derived analytical estimate**. It is based on published regional demand shares and state allocation weights.

Use the wording:

> **Estimated State-wise Gold Consumption**

or:

> **State-level values are analytical estimates based on published regional demand shares and do not represent official state-level statistics.**

## What the dashboard does not claim

It does not claim that:

- state estimates are official government statistics;
- displayed rates are live market prices;
- one jeweller's rate applies to every branch or city;
- the report is investment advice.

## Data wording

Use **Latest Published Data** instead of **Real-time Data** unless a live data connection is added later.
